## 验证过程与边界

- 首轮 61 项通过后收到 R31，补最低时长规则及两个自动用例，再次完整验证 63 项通过。
- 浏览器只读 DOM 环境不提供 performance.now，首次计时读取报错；改用测试端墙钟记录，重新在新标签首访采样。没有向页面注入计时或模拟事件代码。
- 慢图等待 API 曾报 selector deadline，诊断当时目标已可见；随后检查到全部图片就绪、welcome 可见、日志无错误。该情况是工具等待边界，不记录为网页功能失败，也不填精确慢图耗时。
- 没有实体低端设备、新一轮物理触控板/手机触摸或 OS 减少动效验收。减少动效 CSS 分支保留，一秒静态提示不强制播放动画。旧触控板识别器未改动。
- 本轮没有重复浏览器全量故障注入（503、15s 超时、禁用 JS）；相应自动回归和原有恢复实现保留，不能把上版实测写成本版重测。
- 不重新登录或下载外站文档/包体；原资源地址及正文由静态校验和抽查保护。未引入新图片、视频、依赖或远程字体。
- 本地截图在仓库外 design/previews/2026-11-03-v1.3.0/，不进入发布产物。
