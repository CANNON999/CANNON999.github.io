## 开发过程中发现与修正

1. 初次类型检查缺少 `node:fs`/`node:crypto` 类型，加入构建开发依赖 `@types/node@24.19.2`，锁定版本并同步 lockfile。
2. Astro 将页面模块移动到 prerender 目录，基于 `import.meta.url` 查找 public 图片导致构建 ENOENT。改用项目构建工作目录下的 public 路径，后续构建成功。
3. 原生 DPR 改变但物理画布大小不变时，旧条件可能漏掉变换矩阵更新。将矩阵更新与重新分配画布分离，增加 P07 回归。
4. 调整初始粒子横向覆盖范围，避免右边一段开始时没有粒子；微调暖光和少量亮点。暂停时保持当前粒子时间，避免跳回初始构图。
5. pnpm 在受限执行环境尝试自动协调模块目录并因无 TTY 退出；依赖锁定安装成功后，在可访问已有缓存的环境完成同一 `pnpm verify`，没有跳过测试。
6. 一次把 6 个原生滚动命令放在约 1s 的工具调用内，最后两个同向事件被当作同一手势尾部，得到 5 次选择；这组命令不含手指再次加速轨迹。没有据此改动用户已验收的识别器，改为逐步浏览器检查，并保留 W02/W10/W19 的确定性新手势回归。
7. 响应式覆盖最初作用于当前活动的测试标签页，而非原预览窗口；读取 DOM 尺寸发现未生效，改用专用活动标签页后确认真实 390/320 尺寸，再记录结果。未把未生效的尺寸当作通过。
8. `ccac2c6` 部署成功后的真实首访显示 4/9 就绪时触发 12s 恢复提示，随后 18 个图片元素都已加载，页面却仍停留在提示。新增独立的全部解码完成通知，超时后继续观察实际解码；全部成功后自动进入，并以 generation 防止旧重试覆盖新状态。保留 L07–L08 和 B29 防止回归。

## 验证边界

- 本次没有重新完成实体 Mac 手感、iPhone/Android、Safari/Firefox、跨物理显示器切换、系统减少动态效果的实机验收。上一版用户已确认触控板顺畅，本次未修改 `wheel-navigation.ts`；W01–W19 全部保留并通过。
- B14 的系统偏好、B17 的浏览器全局禁用 JS 未实机重测；手动暂停与模块失败分别有浏览器证据，无 JS 的默认 HTML 结构保留。不能把它们等同于系统设置验收。
- 浏览器缓存被清除、网络持续故障或以后新增详情大图时，站内跳转仍可能重新请求图片；本版保证首次首页先准备全部首页图，正常站内切换不强制开场，不声称永久离线缓存。
- 参考画面是视觉方向，本版为原创程序化近似，不声称逐帧复刻 Sony 的渲染器。
