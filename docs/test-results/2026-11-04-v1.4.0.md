## 故障、修复与验证边界

- 初次新测试导入缺 .ts 扩展名失败，修复后完整重跑，没有跳过。
- 本机端口监听最初被沙箱限制，以授权本机服务方式启动；无公网服务器。一次构建缺 CI=true 停在 pnpm 非交互检查，补齐后正常。
- 浏览器工具混合原生 AX 和视口模拟时 innerHeight 会变化（819→823 等），原生 View Transition 因 viewport changed 被取消；此时增加 ready 拒绝捕获和内容入场回退。固定视口并统一使用 DOM 操作后，实际原生分层快照正常运行；关键帧有旧作品集与新档案头像/标签的交叠。减少动效、取消及旧浏览器回退由自动用例保护。
- 未使用真实 Windows 鼠标、高分辨率滚轮、实体 Mac 触控板录制或低端硬件测试。浏览器不提供确切输入设备类型；模糊输入保守一步，真实驱动可能需要后续调节。未把模拟滚动称作用户手感验收。
- 未逐个进入外部百度网盘/Bilibili下载或登录；保留既有资源链接，站内构建引用全部检查。游戏封面已本地保存，不依赖 Steam 在线状态。
- 没有进行纸张打印机实测；打印样式保留显示所有章节，无脚本正文仍完整。Safari/Firefox 物理浏览器未执行，本轮兼容通过功能检测与控制器测试覆盖。
