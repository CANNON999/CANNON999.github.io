# V1.3.1 验证记录

日期：2026-11-03（Asia/Shanghai）。基线：5abfbe9。目标：R32 以 Mac 为参照统一桌面 UI 比例，R33 作品预览及 Hub 主标题粗体。

## 环境与方法

- macOS、Microsoft Edge；实际默认视口 1504×862 CSS 像素、DPR 2。用户 Windows 截图尺寸为 2552×1308；本轮用响应式视口模拟该尺寸及其他分辨率，不是 Windows 实机验收。
- Node 24、pnpm 11.25.0、Astro 7.4.2；构建产物由 4321 本地静态服务器提供。
- 测量前使用页面暂停动效开关，避免读取封面变大中的中间帧；交互验收前恢复动效。CSS 计算值和 DOM 边界为真实浏览器读取，滚轮输入由 UI 自动化产生。
- 桌面默认比例为 max(1,min(视口宽/1504,视口高/862))；同一 rem 单位控制字号、封面、按钮、卡片和间距。媒体查询仍为 CSS 像素。用户自定义基础字号保留为下限。

## 验证边界与记录

- 没有实际 Windows 27 寸显示器、实体手机或低端设备测试。浏览器只能依据可用 CSS 视口缩放，不能根据显示器英寸确定 UI 大小；操作系统缩放和浏览器缩放会改变可用视口。Windows 系统字体继续回退到 Microsoft YaHei，实际字形仍由本机字体决定，所需粗体明确指定为 700。
- 未引入额外渲染循环、远程字体、图片或依赖。Canvas 清晰度/性能控制沿用原逻辑；本轮不把布局测试当作低端性能测评。
- 首次只读 DOM 测量使用的全局 parseFloat 在工具环境不可用，改为返回 CSS 字符串后由测试端解析；不是网页运行报错。截图在动效及绘制稳定后采集，未用过渡帧作最终证据。
- 首访时间来自测试端墙钟，含导航/工具开销；精确一秒下限由既有 G06/G07 自动测试保护。没有重跑慢图、503、15 秒超时、禁用 JS 或 OS 减少动效的整套浏览器故障注入，不将历史实测计作本轮结果。
- 截图和比例测量 JSON 存放在仓库外 `design/previews/2026-11-03-v1.3.1/`，不进入发布产物。
