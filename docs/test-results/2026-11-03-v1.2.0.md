## 发现与修复

1. 首页样式顺序令组件上下居中，改为更明确的 profile 场景选择器，卡片下缘在默认视口 y=809，上方留空至 y≈414。
2. 常规和短桌面的个人档案文字挤到卡片外。调整内距与层级；1000×600 省去重复标签后六卡 scrollHeight 均不超过 clientHeight。
3. 刷新后 Escape 导致浏览器原生 dialog 关闭，但退场类残留，主界面透明。增加 close 事件兜底、在回退历史前恢复主界面；H11 防止再次发生，并用相同原生 Escape 重测通过。

## 验证边界

- 没有实体低端 Windows/Android 设备，也未新增实体触控板、手机触摸或系统减少动效验收。原用户对 V1.0.1 触控板的“现在顺畅了”是历史验收，本轮未改识别器。
- 外站腾讯文档/百度网盘沿用用户已有链接；验证链接与提取码完整，未重新下载、登录或判断所有外站文件的实时可用性。
- 减少动效由 CSS 分支、控制器测试与手动暂停验证；没有更改用户 OS 设置。
- 产物实测约 1.74MB，首页 9 张唯一 WebP 共约 1.51MB；无新增运行时依赖、视频、远程字体或主机原素材。具体性能/容量解释在对话交付。
