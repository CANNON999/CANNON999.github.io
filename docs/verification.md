## 浏览器检查

使用本机浏览器先检查开发版本，再打开同一构建产物的静态预览。

- 桌面 1280×720：默认个人介绍、紧凑横排封面、仅选中项放大、标题位于选中封面右下侧。
- 滚轮向下：从个人介绍切换到右侧的「深渊入口」。
- 键盘 ArrowRight：切换到「梦醒之城」；进入项目按钮打开独立详情页。
- 详情页滚轮正常纵向阅读，不触发横向作品切换。
- 作品库选择「关卡设计」：显示 2 件作品并更新筛选网址。
- 手机 390×844：无页面横向溢出，图片无损坏，单个作品面板可见。
- 手机末项：End 选中「机器人建模」，封面和标题完整进入可见区域，下一项按钮禁用；Home 返回个人介绍。
- 320×568 短屏：页面可正常纵向滚动，作品不会因阅读滚动被意外切换。
- 暂停动效：按钮状态、重播禁用状态和存储偏好正常；重新开启动效后可以重播。
- 最终静态版本的开场重播、立即跳过和焦点返回正常。
- 已检查的页面没有浏览器控制台警告或错误。

## 验证边界

- 手机检查使用响应式视口，未在实体手机上验收触摸手势。
- 已实现系统减少动态效果与后台暂停；未修改用户系统设置进行端到端模拟。
- 未做多设备帧率基准，不承诺所有设备恒定 60 FPS。粒子使用缓存光斑、按时间驱动的运动、移动端降密度及 DPR 上限。
- 百度网盘和腾讯文档入口沿用旧站原链接，未下载大型项目文件，也未验证所有第三方资源的登录或有效期状态。
- GitHub 连接创建分支返回 403，未推送、未执行远端 Actions，也未改变现有线上站点；部署配置需在获得仓库写入权限后实测。
