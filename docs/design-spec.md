# 当前个人主页设计细则

版本：V1.3.1。维护日期：2026-11-03（Asia/Shanghai）。需求来源：[需求记录](requirements.md)。本文件描述当前设计，早期竖排方案不再生效。

## 定位与内容

- 面向游戏行业同行、招聘者和对作品感兴趣的访客，以浏览作品、了解贡献、直接查看演示为核心。
- 品牌为 CANNON，姓名肖冠荣，邮箱沿用旧站。初始状态是独立的“欢迎你”场景；个人介绍是第二个选项。
- 保留 10 件真实作品：深渊入口、梦醒之城、坦克射击原型、程序化黑洞、空间站、游戏拆解、山洞游戏场景、交大庙门、风格化场景、机器人建模。连同欢迎你、个人介绍，首页共 12 个选择项。
- 类型为关卡 2、开发 1、美术 6、拆解 1；以后由内容集合自动计算，不将这些数量写死在业务逻辑里。
- 展示本人实际贡献、工具、简述和资源；无材料时不虚构任职、获奖、发布日期或项目参与情况。

## 视觉与布局

- PS5 风格的紧凑选择逻辑、暗色空间和柔光层次；个人品牌与原始游戏作品素材属于本站内容。没有将 PS5 原视频、控制器按钮图标或 Sony 标识作为网站品牌。
- 基础背景 `#080d17`，文字 `#f1f4fa`，辅助文字 `#a8b6ca`；项目可提供独立点缀色。字体使用系统字体与苹方/微软雅黑回退，不依赖远程字体服务。
- 桌面横向留白约 7.2vw。顶栏左侧为同字号的“个人主页 / 作品集”（默认 25px，活动项 650、非活动项 300），右侧依次为关于我、联系、头像与肖冠荣。作品集保留原筛选页面。底部保留键盘提示、暂停与重播。
- 非选中封面保持小尺寸，只放大当前项。Mac 基准下小封面 82px、选中 132px、间距 9px；大屏按同一比例放大。标题位于选中大封面右侧、相邻小封面下方，不能改成所有封面都展示一排标题。封面不再叠加 ABYSS 等短标签。
- 项目背景使用真实封面，左侧及底部渐暗以保证正文可读；背景交叉淡入，当前切换的图片完成解码才替换，不让过时的异步加载覆盖新选择。

### 显示尺寸：以 Mac 视口为基准

基准为本机实际 1504×862 **CSS 像素**、默认根字号 16px。缩放因子为 `max(1, min(视口宽 / 1504, 视口高 / 862))`；CSS 统一使用 rem，根字号通过 `max(100%, min(100vw / 94, 100svh / 53.875))` 连续计算。保留浏览器默认字号下限，打印恢复默认根字号。

导航、封面、字、按钮、卡片、圆角、描边、间距与进入位移均使用同一单位；去掉之前 ≥1700px 的几组独立放大规则，避免跳变和二次放大。背景保持铺满，横向留白继续随视口变化。宽高比不同的窗口允许更多左右留白；不对整页做 transform/zoom 拉伸。手机和小桌面维持原响应式断点，控件不会被等比缩成难以点击的尺寸。

| 视口 / 缩放 | 小 / 大封面 / 间距（约） | 主要表现 |
| --- | --- | --- |
| 1504×862 / 1.0000 | 82 / 132 / 9px | Mac 基准，原有布局尺寸 |
| 1920×1080 / 1.2529 | 103 / 165 / 11px | 各组件同步增大 |
| 2552×1308 / 1.5174 | 124 / 200 / 14px | 用户截图对应视口 |
| 2560×1440 / 1.6705 | 137 / 221 / 15px | 2K 视口 |
| 3840×2160 / 2.5058 | 205 / 331 / 23px | 4K 视口 |
| 601–1180px 宽的小窗口 | 72 / 116 / 8px | 维持原紧凑模式，≤900px 隐藏右资料卡 |
| ≤600px 宽 | 58 / 92 / 7px | 24px 页边距、移动导航与阅读布局 |

作品预览 `.project-copy h1` 与共享 Hub 大标题统一 `font-weight:700`，使用现有系统字体回退（Windows 为 Microsoft YaHei 等）。预览与 Hub 在 Mac 基准字号约 73.696/79.712px，较大屏幕等比放大；仅封面右下方小标题 `.cover-name` 保持 300。避免以“中粗 500”要求只有常规/粗体两档的字体。欢迎姓名仍为 700。

## 作品展示 Hub

参考 `05-game-hub-friends-who-play.jpg`：作品封面铺满背景、上方小封面和名称、左下大标题与作品标语、白色胶囊主按钮和更多入口，底部三张深灰资源卡。桌面三卡完整呈现；手机单列、可自然上下阅读。

- 顶部左侧依次为返回箭头、小封面、白色分类标记和项目名；右侧只保留作品集入口。返回链接 Mac 基准 52×52px（大屏同比放大）、手机 44×44px，静息透明，悬停和键盘选中时 220ms 亮起白圆、箭头变深色，加轻微外环与柔光；按下缩至 95%。提供“返回作品选择”可访问名称，独立页链接 /#id，内嵌页关闭 Hub。系统减少动效时无过渡。
- 主按钮从真实资源中依次选文档、试玩下载、视频、工程；无资源时链接到本站作品介绍。显示具体动作，不把下载包描述成网页内即时试玩。
- 资源卡固定为设计文档、演示视频、下载与工程。保留每个同类链接及提取码；空卡只有“待补充”说明，不放死链或虚构进度、奖杯、好友数。
- 首页已经渲染每个 Hub 的轻量 HTML，封面复用首次加载的 9 个 URL。单击封面、项目入口或 Enter 打开原生 dialog，浏览器不跳转新文档；以 `#hub-id` 保存可恢复状态。主要动作获焦，后台不可操作，Escape/返回/历史操作关闭后焦点回到所选封面。
- 进入时先保留同一背景；作品栏上移 45px、450ms 淡出，Hub 顶部与标题在 70–80ms 后开始 600–650ms 进入，主按钮延迟 150ms，卡片自 210ms 起每张错开 45ms。背景约 900ms 微缩放 1.8%；仅对 transform/opacity 动画，不做全屏实时模糊。
- 返回约 360ms，旧关闭回调不会关闭新 Hub；浏览器直接关闭原生 dialog 也必须清除退场样式。暂停/系统减少动效时取消 CSS 过渡。
- 独立 `/works/id/` 渲染同一组件，并保留 `#project-story` 原 Markdown 正文。复制、外部打开、无 JS 访问均使用真实路径。首页转场的“免加载”不等于外站文档/网盘免网络等待。

## 输入与选择

1. 横向手势向右浏览下一作品，反向返回；滚轮向下映射下一作品，向上映射上一作品。使用浏览器的滚动方向，遵循用户系统自然滚动设置。
2. 常规轻扫选中一项。像素输入累计约 36px 触发，110ms 无有效输入可开始新手势；惯性未结束时，通过衰减后的再次加速识别新意图，两次有效采样确认以抑制孤立异常脉冲。
3. 新手势不受 460ms 动画锁限制；明显反向立即开始新的累计。极小抖动不会切换。持续稳定推移可以继续浏览，连续推进间隔至少约 220ms。
4. 行/页单位滚轮视为离散输入；像素、行、页单位统一处理。浏览器没有通用的触控板“手指离开”标记，参数属于启发式识别，硬件手感仍需要设备验收。
5. 短屏或放大后，正文允许正常纵向阅读；项目摘要区域的横向手势仍选择作品（固定个人组件和已打开 Hub 除外）；作品栏内的纵向滚动仍映射选择。Ctrl/Command 手势及捏合缩放交给浏览器。
6. 点击欢迎封面选择欢迎页，点击个人介绍封面选择六组件；单击作品封面直接展开 Hub。左右按钮、方向键和滚轮用于预览选择；焦点在封面栏时 Home/End 跳首尾，Enter 在作品项展开 Hub，在欢迎项进入个人介绍，在个人介绍项打开关于我档案。底部 Enter 提示随场景更新。组件内普通链接保留本来行为。Command/Ctrl/中键继续使用独立作品链接。
7. 手机单指水平滑动超过 45px 且水平位移大于纵向位移时切换，滑动后短暂阻止误点击；取消及多指输入不触发该选择。
8. 首尾按钮禁用，选择索引钳制在有效范围。每次选择同步背景、面板、标题、计数、地址 hash、ARIA 状态；封面位置按当前 rem 和根字号换算为实际 CSS 像素，基于最终尺寸计算，不读取过渡中的临时宽度；预览选择不新增浏览历史记录；展开 Hub 新增一条，关闭后回到同一作品。

## 动效与性能

| 动效 | 当前标准 |
| --- | --- |
| 作品栏位移 | 380ms，可由下一次输入打断 |
| 封面尺寸 | 300ms；仅当前项放大 |
| 正文出现 | 320ms，6px 微移和透明度过渡 |
| 背景 | 620ms 淡入淡出与约 1.2% 缩放 |
| 首次加载 | 首页图片完成解码后进入；首访至少 1000ms，同时加载图片；满足最低时长和全部图片解码两个条件才进入；约 450ms 连续过渡 |
| 手动重播 | 约 3s，同一粒子场继续运行；按钮或 Enter/Escape 可立即进入，不重载图片 |
| 粒子 | 单个 Canvas、6 张 128×128 缓存光斑；桌面最多 720 个、窄屏 380 个；暖金/淡白三层景深、缓慢向右上漂移；完整原生 DPR |

欢迎与个人介绍底色 `#10121d`，左上宽幅暖光、左下冷灰柔光，粒子带从左下向右上延伸；近景光点较大且失焦，中景为金色柔边圆斑，远景为细小锐利亮点。主文案区域保持足够暗度。依据本地 Sony 参考帧重建构图，不加载原视频、全屏低清位图或远程字体。

画布 backing store 为 `round(CSS 宽高 × devicePixelRatio)`；监听窗口和像素密度变化，包括暂停时换屏/缩放。不是将低清画布放大。只在加载/重播/欢迎/个人介绍显示时绘制；作品画面和隐藏标签页取消帧循环，返回后继续原粒子时间，不重新启动第二个画布。

默认约 60 次绘制/秒。连续 90 次采样中超过 48 次间隔 >26ms 或 JS 绘制提交 >8ms，逐级降到约 72%、48% 粒子；最后一级约 30 次/秒。忽略 >120ms 的后台/调试间断，不降低画布清晰度；这是负载保护，不是所有设备流畅度保证。暂停状态存本机；系统减少动态效果时保留静态粒子及必要加载提示，保留一秒静态开场提示，取消重播与过渡。不自动播放声音。

## 首次加载与站内访问

1. 在 `<head>` 执行轻量入口判断，首次绘制前隐藏主界面；加载页显示 CANNON、中央“正在加载作品…”、真实就绪数量和细进度线。加载期间主页不可交互，不允许通过方向键或 Enter 提前露出未就绪画面。
2. 对首页封面和摘要图全部 eager 请求；按 URL 去重统计，同时等待每个实际 `<img>` 的 `decode()`。当前 18 个元素对应 9 个本地 WebP，下载总量约 1.5MB。从显示加载页起同时开始至少 1000ms 的计时，全部成功且最低时长满足后才自动进入；较慢图片就绪后不额外再等待一秒。切换项目时复用这些素材，背景替换仍等待解码且排除过时请求。
3. 12s 尚未就绪时显示说明与“重新加载 / 先进入主页”，下载/解码继续运行；所有图片晚到后仍自动进入。只有用户主动选择才在不完整状态下进入。成功只写一次素材指纹，失败不冒充准备完成。旧重试请求的迟到结果不能覆盖新一轮状态，坏图后续成功时恢复。
4. 本标签页 `sessionStorage` 记录基于真实图片内容的指纹；同版本刷新、同站详情/作品库返回跳过开场，作品栏内切换完全不重新等待。存储不可用时仍通过同源 referrer 识别站内返回。新增/替换封面自动更新指纹，直接访问时重新准备。
5. Hub 不增加独立图片或第三方脚本，复用已经解码的封面。只预加载当前主页会用到的图片，作品正文以后新增的大图仍由详情页按需加载；百度网盘、外部视频、文档不提前下载。站内返回在浏览器缓存正常时直接展示；浏览器清除缓存或回收解码内存后可能需要重新请求/解码，不用永久缓存承诺替代实测。
6. JavaScript 完全关闭时默认直接显示可阅读 HTML；入口脚本已运行但主模块失败时，15s 恢复静态主页，避免永久遮挡。浏览器后退缓存恢复会重新启动必要的粒子或未完成的图片准备。

## 可访问性与内容维护

- 使用真实链接、按钮、tablist/tab/tabpanel、`aria-selected`、可见键盘焦点和选择状态播报。无 JavaScript 时可以通过封面链接、作品库和详情页阅读。
- 支持短屏、移动版、文字放大及打印档案；不要为了全屏效果禁止详情页纵向滚动。
- 统一缩放入口为 `src/styles/display-scale.css`；尺寸修改用 rem（基准 1rem=16px），断点仍用 CSS 像素，避免浏览器响应式条件发生意外变化。`rail-layout.ts` 消费同一组 rem 封面尺寸；构建校验保护该单位约定。
- 个人资料在 `src/data/profile.json`；作品在 `src/content/projects/*.md`，包含标题、分类、排序、简介、贡献、工具、资源及可选年份等字段。
- 新作品脚本默认生成草稿，不覆盖同名文件。`draft: true` 不发布；非拆解类公开作品需要本地封面。新增作品后自动更新首页、作品库、详情及 sitemap。
- 图片存于 `public/images/`，优先 WebP；外部资源采用 HTTPS，网盘提取码可展示并包含在链接中。

## 发布与变更约束

Astro 静态输出，由 GitHub Pages 托管，公开地址固定为 https://cannon999.github.io/ 。无数据库、常驻本地服务或付费 API 要求。发布分支 `master`，每次推送由 GitHub Actions 执行测试、类型检查、构建、资源校验及部署。

每次修改都更新关联需求、设计条目、日志、测试用例及版本测试报告。常规发布已获用户授权；发布失败不能报告上线。旧站备份分支必须保留。当前设计规则与代码不一致时先定位并修正，不通过删除测试掩盖问题。
