## V1.0.1 — 触控板与持续维护机制（2026-10-30）

1. **接收需求**：R12 报告 Mac 触控板第一次滑动有效、后续失效，并要求更平滑；R13 要求需求文档；R14 要求当前设计细则；R15 要求逐步开发日志；R16 要求新增功能用例和回归测试。
2. **检查基线**：读取协作约定，确认 `master` 工作区干净，获取远端最新状态；检查 `console.ts`、样式、现有构建校验和页面结构。
3. **定位漏滑**：旧 `consumed` 状态仅在超过 180ms 无事件时解除，触控板惯性持续刷新时间；另有 460ms 动画冷却。矮窗口保护逻辑还会忽略正文区域的横向输入。
4. **复现旧问题**：用两组带加速/衰减的时间戳轨迹重放旧逻辑，确认两次轻扫只触发一次。此为合成轨迹，不称为实体 Mac 录制。
5. **实现输入模块**：新增 `src/scripts/wheel-navigation.ts`，独立归一化单位、保留浏览器缩放/正文阅读，按空隙、反向、新加速、持续输入识别选择，过滤惯性及孤立尖峰；与动画耗时解耦。
6. **接入页面**：`console.ts` 使用新模块；点击、键盘、重播、后台切换时重置旧输入状态。修复矮窗口正文横向操作。主页其余内容和资源沿用既有资料。
7. **调整过渡**：作品栏 560→380ms，封面尺寸 420→300ms，正文 460→320ms，背景 820→620ms；缩短微移幅度，保留现有色彩、横排及放大规则。
8. **建立测试**：新增 W01–W18 输入测试；首次执行发现测试辅助函数缺少闭合括号，补齐后 18 项全部通过。新增 C01–C03 内容创建脚本回归，验证草稿、拒绝覆盖和路径边界。
9. **接入发布门槛**：`package.json` 加入 `pnpm test`；`pnpm verify` 在构建之前执行所有自动测试；沿用现有 GitHub Actions，测试失败不会进入部署。版本更新为 1.0.1。
10. **处理本机工具问题**：首次 pnpm 调用因受限环境的依赖缓存读取/自动校验失败；先用 Node 直接运行用例，再使用获准的正常缓存执行完整验证；未更换框架或新增运行时依赖。
11. **建立文档**：新增需求、当前设计、日志、测试用例和版本测试报告；在 README 和 AGENTS 中要求后续每次开发持续维护。历史未知日期保留为未知，撤销要求单独标记。
12. **浏览器回归**：按测试目录执行本地静态版本检查。连续“右、右、左、右、左、左”均对应预期作品；每次只有一个选中 tab 和一个可见 panel。后续检查和最终结果见版本报告。
13. **补测较轻输入**：增加 W19，基础轻扫尾部后以 4px 采样持续轻扫，初次测试未识别第二次输入；调整新加速的最低幅度与持续确认阈值，保留双采样、累计距离及孤立尖峰过滤，然后重跑全部测试。

发布提交、Actions 结果及设备验证边界在 [本版测试报告](test-results/2026-10-30-v1.0.1.md) 记录。报告中未验证的项目不视为通过。
