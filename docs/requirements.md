## 本次变更的具体验收

### R12：触控板与滚轮

1. 两次同向轻扫之间仍有惯性事件时，两次输入都可以产生选择；左右反向无需等待 460ms。
2. 单次轻扫的单调衰减尾部、极小反弹及孤立异常脉冲不额外切换项目。
3. 持续稳定推移可以继续浏览，但不会每帧切换；左右边界不可越界。
4. 水平输入在矮窗口正文区域有效；纵向输入在可滚动正文区域保留自然阅读，作品栏内仍能切换。
5. 捏合缩放和带修饰键的手势、开场期间不误切作品；键盘、按钮、触摸逻辑保留。V1.2.0 的单击行为按 R25 更新。
6. 新手势可中断正在执行的视觉过渡；无须等待图片淡入结束。暂停或系统减少动效不改变输入识别。
7. 自动轨迹测试通过并进行浏览器检查。实体 Mac 的触控板手感独立列为人工验收，不把合成输入称为硬件实测。

### R13–R16：维护机制

每次后续开发按“需求编号 → 验收条件 → 设计变更 → 实现 → 用例 → 结果 → 发布”闭环处理。新需求补充到本文件，当前规则修改到设计细则，操作事实追加到日志，用例和结果分别保存在测试目录与版本报告。没有相关测试时，先补测试再发布；测试失败先修复并重测，不能仅把失败标记为忽略。

### R17–R20：V1.1.0 验收条件

1. 个人介绍与加载页使用同一个实时粒子画布，构图依据本地参考帧 `04-startup-gold-dust.png`、`06-login-gold-particles.png`；Sony 原视频不随站点下载。
2. DPR 2 时画布宽高均为 CSS 尺寸的两倍；DPR 3、分数缩放、调整窗口也正确。虚焦属于景深效果，不依靠降低画布分辨率制造。
3. 默认上限约 60 次绘制/秒；持续负载高时优先减少粒子，必要时约 30 次/秒；不宣称所有设备恒定 60 FPS。暂停、后台、作品画面不持续绘制粒子。
4. 模拟慢图时主界面不可见且不可操作，中央加载状态与图片就绪数对应；18 个图片元素（9 个唯一 URL）完成解码后自动显示。
5. 单个图片失败或超过 12 秒不无限阻塞，用户可以重试或明确选择先进入；仍在下载的图片若随后全部完成解码，应自动进入，不能停在过时的错误提示。不会冒充全部图片已加载。脚本未启动时 15 秒恢复可阅读 HTML，无 JavaScript 时无需等待。
6. 作品栏内切换、详情/作品库返回及同标签页正常刷新不强制重播加载；清空缓存、极差网络等情况下，站内返回图片仍可能需要浏览器重新请求，但不出现强制开场。
7. 系统减少动态效果或手动暂停时，保留静态背景和图片准备提示，取消强制动效与最短展示时间。原触控板、键盘、首尾边界、窄屏、作品资源回归通过。

### R21–R27：V1.2.0 验收条件

1. 主导航的两项字号相同，活动态仅通过字重与亮度区分；关于我、联系、姓名靠右。
2. 桌面只有三列六张个人组件，上方保留完整背景；不增加第七张或横向裁切的卡片。常见桌面/移动视口无需滚动即可看到六张；极矮或放大时优先保证可阅读。
3. 组件区域不响应切换作品的滚轮/触摸；封面栏和空白区域保留原手势识别。删除 cover-word，同时保留选中大图标右侧标题。
4. 点一次作品封面即可打开 Hub。视觉参考本地 05 截图与 01 转场录像；首页 → Hub 不重载文档，不转圈，不重播粒子加载。
5. 10 件作品均有 Hub；文档/视频/下载三张资源卡可完整显示。原链接、视频数量和提取码不得丢失；无资源时明确待补充，主按钮仍有有效去向。
6. 返回按钮、Escape、浏览器后退与前进、刷新 #hub-id、深链接、无脚本链接路径均可工作。退出保留选中作品，焦点回到封面；快速反向操作不留空白或过期动画。
7. 原项目 Markdown 正文和独立路径继续保留。手机 Hub 可自然纵向阅读，不把正文压入不可滚动的固定屏幕。
8. 更新用例、日志和当前设计，执行完整验证及浏览器回归后按已有授权推送上线。
