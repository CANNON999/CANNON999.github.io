## 本次变更的具体验收

### R12：触控板与滚轮

1. 两次同向轻扫之间仍有惯性事件时，两次输入都可以产生选择；左右反向无需等待 460ms。
2. 单次轻扫的单调衰减尾部、极小反弹及孤立异常脉冲不额外切换项目。
3. 持续稳定推移可以继续浏览，但不会每帧切换；左右边界不可越界。
4. 水平输入在矮窗口正文区域有效；纵向输入在可滚动正文区域保留自然阅读，作品栏内仍能切换。
5. 捏合缩放和带修饰键的手势、开场期间不误切作品；已有键盘、按钮、点击、触摸逻辑保留。
6. 新手势可中断正在执行的视觉过渡；无须等待图片淡入结束。暂停或系统减少动效不改变输入识别。
7. 自动轨迹测试通过并进行浏览器检查。实体 Mac 的触控板手感独立列为人工验收，不把合成输入称为硬件实测。

### R13–R16：维护机制

每次后续开发按“需求编号 → 验收条件 → 设计变更 → 实现 → 用例 → 结果 → 发布”闭环处理。新需求补充到本文件，当前规则修改到设计细则，操作事实追加到日志，用例和结果分别保存在测试目录与版本报告。没有相关测试时，先补测试再发布；测试失败先修复并重测，不能仅把失败标记为忽略。
